# TCL Smart Comfort

Zeitgesteuerte Helligkeit und Eye Care für den TCL 55P8L (Google TV), als eigenständige App auf dem
Fernseher. Kein Root, kein Bootloader-Unlock, keine Firmware- oder Factory-Menu-Änderung.

**Stand: Geräteprüfung (nur lesend).** Die App wird erst entwickelt, wenn die Prüfung am echten
Fernseher zeigt, dass es geht. Anleitung: [docs/GERAETEPRUEFUNG.md](docs/GERAETEPRUEFUNG.md).

| Pfad | Inhalt |
|---|---|
| `tools/tv-probe.sh` | Prüfskript für den Mac, ändert am TV nichts |
| `docs/GERAETEPRUEFUNG.md` | Wireless ADB einrichten, Claude Code auf dem Mac verbinden, Prüfablauf |
